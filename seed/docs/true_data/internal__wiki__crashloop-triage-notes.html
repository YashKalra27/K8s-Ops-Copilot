CrashLoopBackOff triage notes (team wiki)

Synthetic internal wiki page for the ADV RAG demo.

A pod in CrashLoopBackOff is restarting repeatedly; Kubernetes waits longer between each restart (back-off). Start with kubectl describe pod <pod> to read the last state and exit code, then kubectl logs <pod> --previous to see the logs of the crashed container. Exit code 137 usually means OOMKilled; exit code 1 usually means an application error or bad configuration.

Check recent ConfigMap or Secret changes and failing liveness probes before touching resource limits.
