Generative AI · Project Brief

K8s Ops Copilot: a secure, agentic RAG assistant

An LLM-powered copilot that answers questions about Kubernetes operations by retrieving real documentation and querying an incident database, then generating grounded, cited answers in plain English.

Problem statement

Large Language Models write fluent text but do not know an organisation's private data, and without facts they hallucinate. Site-reliability engineers need answers drawn from unstructured documentation (runbooks, Kubernetes docs) and structured operational data (incidents, on-call logs) at once. A plain chatbot also treats any text as an instruction, leaving it open to prompt injection and data leaks. This project builds a generative assistant whose every answer is grounded in retrieved evidence, routed to the right source and protected by layered guardrails.

Generative AI techniques implemented

  • Retrieval-Augmented Generation (RAG): answers come only from passages retrieved from a 6,122-chunk vector store.
  • Embeddings and hybrid search: dense embeddings plus sparse BM25 keywords, fused with Reciprocal Rank Fusion.
  • HyDE: the LLM drafts a hypothetical answer whose embedding finds passages a short question misses.
  • Cross-encoder reranking: 20 candidates re-scored by MiniLM-L-6; the best 5 reach the prompt.
  • Corrective RAG (CRAG): an LLM grades each passage and admits uncertainty instead of guessing.
  • Self-RAG: the model critiques its own draft and retries with a sharper query.
  • Agentic workflow: LangGraph state machine with an LLM intent router and checkpointed state.
  • Text-to-SQL with human-in-the-loop: the LLM writes read-only SQL; the graph pauses for human approval.
  • Conversational memory: “How do I fix it?” is rewritten as “How do I fix ErrImagePull?”.
  • LLM security: 9 layers incl. an injection classifier, hardened system prompt and spotlighting.

Key design choices

  • Fully offline: open-weight qwen2.5:3b via Ollama on an 8 GB laptop; GPT-4o by config.
  • Stress-tested: a 95% noise, 5% signal corpus makes each RAG technique prove its value.
  • Transparent: every pipeline step is streamed live and shown with the answer.
  • Efficient: a 5-tier cache avoids repeated LLM and embedding calls.

Outcomes

  • Cited answers with confidence for docs, database and combined questions.
  • ChatGPT-style interface with saved chats and inline SQL approval.
  • Jailbreak attempts stopped before any model sees them.
  • 82 automated tests pass; a 10-page beginner's guide.
